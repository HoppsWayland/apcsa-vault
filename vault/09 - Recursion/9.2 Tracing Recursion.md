## How to Trace Recursion

Tracing recursion is a key AP exam skill. The best approach:

1. Write out each call as it's made (going down)
2. Then evaluate each return value (coming back up)
3. Substitute return values back into the waiting expressions

---

## Example — Trace `mystery(5)`

```java
static int mystery(int n) {
    if (n <= 1) return 1;
    return n + mystery(n - 2);
}
```

**Going down (calling):**
```
mystery(5) = 5 + mystery(3)
mystery(3) = 3 + mystery(1)
mystery(1) = 1   ← base case
```

**Coming back up (returning):**
```
mystery(1) → 1
mystery(3) → 3 + 1 = 4
mystery(5) → 5 + 4 = 9
```

## Before vs After the Recursive Call

The position of print statements relative to the recursive call changes the output order:

```run-java
public class Main {

    static void before(int n) {
        if (n == 0) return;
        System.out.print(n + " ");    // prints BEFORE calling
        before(n - 1);
    }

    static void after(int n) {
        if (n == 0) return;
        after(n - 1);
        System.out.print(n + " ");    // prints AFTER returning
    }

    public static void main(String[] args) {
        System.out.print("Before: ");
        before(5);
        System.out.println();

        System.out.print("After:  ");
        after(5);
        System.out.println();
    }
}
```

## Tracing with Multiple Recursive Calls — Fibonacci

The Fibonacci sequence: 1, 1, 2, 3, 5, 8, 13... where each number is the sum of the two before it.

```run-java
public class Main {

    static int fib(int n) {
        if (n <= 1) return n;
        return fib(n - 1) + fib(n - 2);
    }

    public static void main(String[] args) {
        for (int i = 0; i <= 8; i++) {
            System.out.print(fib(i) + " ");
        }
    }
}
```

Tracing `fib(4)` shows why this can get complex — each call branches into two more:

```
fib(4) = fib(3) + fib(2)
fib(3) = fib(2) + fib(1)
fib(2) = fib(1) + fib(0)
fib(1) = 1
fib(0) = 0
...
```

## 📌 Summary

- Trace recursion in two passes: going down (each call), then coming back up (each return value) #recursion #pattern #mc_only
- Code **before** the recursive call executes on the way down (top-to-bottom order) #recursion #concept #mc_only
- Code **after** the recursive call executes on the way back up (bottom-to-top order) #recursion #concept #mc_only
- Fibonacci has two recursive calls — each call branches into two more, growing exponentially #recursion #concept #mc_only
- Always identify base cases first when tracing — they're where the recursion bottoms out #recursion #pattern #mc_only
