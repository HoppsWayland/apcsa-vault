## Coding Exercises

## Exercise 1 — Power

Write a recursive method `power(base, exp)` that computes `base^exp` without using `Math.pow()`.

Base case: `exp == 0` → return 1
Recursive case: `base * power(base, exp - 1)`

```run-java
public class Main {

    static int power(int base, int exp) {
        // Your code here

    }

    public static void main(String[] args) {
        System.out.println(power(2, 10));   // 1024
        System.out.println(power(3, 4));    // 81
        System.out.println(power(5, 0));    // 1
    }
}
```
