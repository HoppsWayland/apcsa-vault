# 09 — Recursion

[[Home|← Home]]

Recursion is one of those concepts that feels confusing at first and then suddenly clicks. The key is learning to *trust the recursion* — focus on the base case and the recursive step, and let Java handle the rest.

On the 2025-26 AP exam, you are expected to **trace** recursive code and understand how it works — but writing recursive solutions from scratch is no longer required.

## Key Vocabulary

| Term | Meaning |
|------|---------|
| **Recursion** | A method that calls itself |
| **Base case** | The condition that stops the recursion |
| **Recursive case** | The part where the method calls itself |
| **Call stack** | The chain of method calls waiting to return |
| **Stack overflow** | What happens when recursion has no base case |
