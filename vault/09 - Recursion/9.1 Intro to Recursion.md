## What is Recursion?

A recursive method is one that **calls itself**. That sounds circular — and it would be, without a stopping condition. Every recursive method needs two things:

1. **Base case** — a condition where the method returns without calling itself
2. **Recursive case** — where the method calls itself with a *simpler* version of the problem

```java
public static int factorial(int n) {
    if (n == 0) {          // base case
        return 1;
    }
    return n * factorial(n - 1);   // recursive case — simpler problem
}
```

`factorial(4)` → `4 * factorial(3)` → `4 * 3 * factorial(2)` → `4 * 3 * 2 * factorial(1)` → `4 * 3 * 2 * 1 * factorial(0)` → `4 * 3 * 2 * 1 * 1` = `24`

---

## The Call Stack

Every time a method is called, Java pushes a **stack frame** onto the call stack — a record of where to return and what the local variables are. When a method returns, its frame is popped off.

For recursion, this builds up a chain of waiting calls:

```
factorial(4) waiting for factorial(3)
  factorial(3) waiting for factorial(2)
    factorial(2) waiting for factorial(1)
      factorial(1) waiting for factorial(0)
        factorial(0) → returns 1
      factorial(1) → returns 1 * 1 = 1
    factorial(2) → returns 2 * 1 = 2
  factorial(3) → returns 3 * 2 = 6
factorial(4) → returns 4 * 6 = 24
```

## Try It — Factorial

```run-java
public class Main {

    static int factorial(int n) {
        if (n == 0) return 1;
        return n * factorial(n - 1);
    }

    public static void main(String[] args) {
        for (int i = 0; i <= 7; i++) {
            System.out.println(i + "! = " + factorial(i));
        }
    }
}
```

---

## What Happens Without a Base Case?

```java
public static int badFactorial(int n) {
    return n * badFactorial(n - 1);   // never stops!
}
```

This calls itself forever, building up stack frames until Java runs out of memory and throws a **StackOverflowError**. Always make sure your recursion moves toward the base case.

---

## A Second Example — Sum of Digits

```run-java
public class Main {

    static int sumDigits(int n) {
        if (n < 10) return n;                    // base case: single digit
        return n % 10 + sumDigits(n / 10);       // last digit + sum of rest
    }

    public static void main(String[] args) {
        System.out.println(sumDigits(1234));   // 1+2+3+4 = 10
        System.out.println(sumDigits(999));    // 27
        System.out.println(sumDigits(7));      // 7
    }
}
```

## 📌 Summary

- Every recursive method needs a **base case** (stops the recursion) and a **recursive case** (calls itself with a simpler problem) #recursion #concept #mc_only
- Without a base case, recursion continues until `StackOverflowError` #recursion #gotcha #mc_only
- Each recursive call adds a frame to the call stack; frames unwind as each call returns #recursion #concept #mc_only
- The recursive case must move toward the base case — each call should be a simpler version of the problem #recursion #concept #mc_only
