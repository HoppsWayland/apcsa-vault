## `substring(int from, int to)`

Returns a portion of the String from index `from` up to **but not including** index `to`.

```
String:   H  e  l  l  o
Index:    0  1  2  3  4
```

```java
String s = "Hello";
System.out.println(s.substring(1, 4));   // "ell"  (indices 1, 2, 3)
System.out.println(s.substring(2));      // "llo"  (from index 2 to end)
```

> [!WARNING] The Exclusive End Trap
> `substring(1, 4)` gives you characters at indices 1, 2, and 3 — **not** 4. The end index is always exclusive. This is the single most tested String detail on the AP exam.

**Getting a single character with substring:**
```java
String s = "Hello";
String ch = s.substring(2, 3);    // "l" — one character as a String
```

This is the official AP-exam way to get one character (as a String rather than a char).

## Try It — substring

```run-java
public class Main {
    public static void main(String[] args) {
        String word = "computer";

        System.out.println(word.substring(0, 4));    // first 4 characters
        System.out.println(word.substring(4));        // from index 4 to end
        System.out.println(word.substring(3, 6));     // middle chunk
        System.out.println(word.substring(2, 3));     // single character
    }
}
```

## `indexOf(String str)`

Returns the index where `str` first appears in the String. Returns **-1** if not found.

```java
String s = "Hello World";
System.out.println(s.indexOf("World"));   // 6
System.out.println(s.indexOf("o"));       // 4  (first 'o')
System.out.println(s.indexOf("xyz"));     // -1  (not found)
```

A common pattern: check if something exists before using it:
```java
if (s.indexOf("@") != -1) {
    System.out.println("Looks like an email address");
}
```

---

## `toUpperCase()` and `toLowerCase()`

Return a new String with all characters converted. Remember — the original is unchanged (immutable!).

```java
String s = "Hello World";
System.out.println(s.toUpperCase());   // "HELLO WORLD"
System.out.println(s.toLowerCase());   // "hello world"
System.out.println(s);                 // "Hello World"  — unchanged!
```

These are useful for case-insensitive comparisons:
```java
String input = scanner.nextLine();
if (input.toLowerCase().equals("yes")) {
    // works whether user types "yes", "YES", "Yes", etc.
}
```

---

## `trim()`

Removes leading and trailing whitespace. Useful when processing user input or file data.

```java
String s = "   hello   ";
System.out.println(s.trim());    // "hello"
System.out.println(s.length());  // 11
System.out.println(s.trim().length());  // 5
```

---

## Chaining Methods

Since each method returns a new String, you can chain them:

```java
String result = "  Hello World  ".trim().toLowerCase();
System.out.println(result);   // "hello world"
```

Read left to right: trim the spaces, then lowercase the result.

## Try It — String Methods

```run-java
public class Main {
    public static void main(String[] args) {
        String sentence = "  The Quick Brown Fox  ";

        System.out.println(sentence.trim());
        System.out.println(sentence.trim().toLowerCase());
        System.out.println(sentence.indexOf("Quick"));
        System.out.println(sentence.trim().substring(4, 9));

        // Finding and extracting
        String email = "student@school.edu";
        int atSign = email.indexOf("@");
        System.out.println("Username: " + email.substring(0, atSign));
        System.out.println("Domain: " + email.substring(atSign + 1));
    }
}
```

## 📌 Summary

- `substring(from, to)` — end index is **exclusive**: `"Hello".substring(1, 4)` → `"ell"` #strings #syntax #gotcha
- `substring(from)` — from index to end of string #strings #syntax
- Single character as String: `s.substring(i, i+1)` — the AP exam way #strings #pattern
- `indexOf(str)` — returns first index of `str`, or `-1` if not found #strings #syntax #algorithm
- `toUpperCase()` and `toLowerCase()` return new Strings — original unchanged #strings #syntax #gotcha
- `trim()` removes leading and trailing whitespace #strings #syntax
- Methods can be chained: `s.trim().toLowerCase()` #strings #pattern
