## What is a String?

A `String` is a sequence of characters. Unlike `int` or `double`, String is not a primitive type — it's an **object**. That distinction matters a lot, and we'll come back to it in [[02 - Strings/2.3 String Comparisons|2.3 String Comparisons]].

```java
String name = "Alice";
String greeting = "Hello, World!";
String empty = "";           // empty String — valid, not null
```

Notice Strings use **double quotes**. Single quotes are for `char` (a single character):

```java
char letter = 'A';           // char — single quotes
String word  = "A";          // String — double quotes, even if just one character
```

---

## String Length

The `.length()` method returns the number of characters in a String.

```java
String word = "Java";
System.out.println(word.length());   // 4
```

> [!NOTE] length() vs length
> Arrays use `.length` (no parentheses). Strings use `.length()` (with parentheses). This trips people up constantly — the difference is that `length()` is a method call on a String object, while `.length` is a field on an array.

---

## Indexing — Characters Have Positions

Every character in a String has an **index** starting at **0**.

```
String:   J  a  v  a
Index:    0  1  2  3
```

The last character is always at index `length() - 1`. This is a very common exam pattern.

---

## Strings are Immutable

Once a String is created, **it cannot be changed**. Methods that appear to modify a String actually return a *new* String — the original is untouched.

```java
String s = "hello";
s.toUpperCase();                      // does nothing useful!
System.out.println(s);               // still "hello"

String upper = s.toUpperCase();      // correct — capture the new String
System.out.println(upper);           // "HELLO"
```

This is one of the most common beginner mistakes with Strings.

---

## String Concatenation

You already saw this in [[01 - Java Fundamentals/1.2 Operators and Expressions|1.2 Operators and Expressions]] — the `+` operator joins Strings together. Any non-String value is automatically converted:

```java
String name = "Alice";
int score = 95;
System.out.println("Student: " + name + ", Score: " + score);
// Student: Alice, Score: 95
```

## The `char` Type

A `char` holds exactly one character, using single quotes:

```java
char first = 'J';
char digit = '5';
char space = ' ';
```

You can get a specific character from a String using `charAt(index)`:

```java
String name = "Java";
char c = name.charAt(0);     // 'J'
char last = name.charAt(name.length() - 1);   // 'a'
```

> [!NOTE] charAt and the AP Exam
> `charAt()` is not on the official AP Java Quick Reference sheet for 2025-26, but it's still a valid Java method and perfectly fine to use. The College Board simply doesn't guarantee it will appear in exam questions — but knowing it makes your life easier. When you need a single character in an exam context, `substring(i, i+1)` is the "official" approach.

## Try It — charAt

```run-java
public class Main {
    public static void main(String[] args) {
        String word = "Computer";

        System.out.println(word.charAt(0));                    // first char
        System.out.println(word.charAt(word.length() - 1));    // last char

        // Loop through characters
        for (int i = 0; i < word.length(); i++) {
            System.out.print(word.charAt(i) + " ");
        }
        System.out.println();
    }
}
```

## 📌 Summary

- `String` is an object, not a primitive — variables hold a reference, not the value itself #strings #concept
- String indices start at `0`; last index is `length() - 1` #strings #syntax
- Strings are immutable — methods return a new String, they don't change the original #strings #concept #gotcha
- Always save the result: `s = s.toUpperCase();` not just `s.toUpperCase();` #strings #gotcha
- `char` uses single quotes: `'A'`; `String` uses double quotes: `"A"` #strings #syntax
- `charAt(i)` returns the `char` at index `i` — valid Java, just not on the AP Quick Reference #strings #syntax
