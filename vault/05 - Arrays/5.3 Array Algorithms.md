## The Core Array Algorithms

These algorithms come up constantly on the AP exam. Know them cold — not just what they do, but how to write them from scratch.

---

## Sum and Average

```run-java
public class Main {
    public static void main(String[] args) {
        int[] scores = {85, 92, 78, 90, 88, 76, 95};

        int sum = 0;
        for (int score : scores) {
            sum += score;
        }

        double average = (double) sum / scores.length;
        System.out.println("Sum: " + sum);
        System.out.println("Average: " + average);
    }
}
```

> [!TIP] The Cast
> `(double) sum / scores.length` — casting `sum` to double ensures decimal division. Without it you'd get integer division and lose the decimal part.

## Finding the Minimum and Maximum

The key insight: initialize your running min/max to the **first element**, not to 0 or some arbitrary number.

```run-java
public class Main {
    public static void main(String[] args) {
        int[] nums = {34, 12, 67, 8, 45, 23, 91, 5};

        int max = nums[0];   // start with first element
        int min = nums[0];

        for (int i = 1; i < nums.length; i++) {   // start at index 1
            if (nums[i] > max) max = nums[i];
            if (nums[i] < min) min = nums[i];
        }

        System.out.println("Max: " + max);
        System.out.println("Min: " + min);
    }
}
```

> [!WARNING] Why Not Initialize to 0?
> If all values in the array are negative, initializing `max = 0` would give you a wrong answer. Always start with an actual element from the array.

## Counting Elements That Match a Condition

```run-java
public class Main {
    public static void main(String[] args) {
        int[] scores = {85, 92, 78, 90, 55, 88, 62, 95, 47};

        int passingCount = 0;
        for (int score : scores) {
            if (score >= 60) {
                passingCount++;
            }
        }

        System.out.println("Passing: " + passingCount);
        System.out.println("Failing: " + (scores.length - passingCount));
    }
}
```

## Searching — Does a Value Exist?

```run-java
public class Main {
    public static void main(String[] args) {
        String[] names = {"Alice", "Bob", "Carol", "Dave", "Eve"};
        String target = "Carol";
        boolean found = false;

        for (String name : names) {
            if (name.equals(target)) {
                found = true;
            }
        }

        System.out.println(target + " found: " + found);
    }
}
```

To also find the *index* where it appears, switch to a regular for loop:

```java
int foundIndex = -1;
for (int i = 0; i < names.length; i++) {
    if (names[i].equals(target)) {
        foundIndex = i;
    }
}
```

Using `-1` as a sentinel value (meaning "not found") is a classic pattern — you'll see it in [[08 - Searching and Sorting/8.1 Linear and Binary Search|8.1 Searching]] too.

## Reversing an Array

To reverse in-place, swap elements from the outside in:

```run-java
public class Main {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 4, 5, 6};

        // Print original
        System.out.print("Before: ");
        for (int n : arr) System.out.print(n + " ");
        System.out.println();

        // Swap from both ends toward the middle
        for (int i = 0; i < arr.length / 2; i++) {
            int temp = arr[i];
            arr[i] = arr[arr.length - 1 - i];
            arr[arr.length - 1 - i] = temp;
        }

        System.out.print("After:  ");
        for (int n : arr) System.out.print(n + " ");
    }
}
```

> [!NOTE] The `temp` Variable
> You need a temporary variable to swap two values. Without it, you'd overwrite one of the values before saving it. This swap pattern (`temp = a; a = b; b = temp`) is fundamental — memorize it.

## Shifting Elements

Moving elements left or right is a common operation (it's the core of insertion sort):

```run-java
public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40, 50};

        // Shift everything left by one (index 0 is lost)
        for (int i = 0; i < arr.length - 1; i++) {
            arr[i] = arr[i + 1];
        }
        arr[arr.length - 1] = 0;   // fill last spot

        for (int n : arr) System.out.print(n + " ");
    }
}
```

## 📌 Summary

- Sum/average: initialize accumulator to `0` before loop; cast to `double` for average #arrays #algorithm #pattern
- Min/max: initialize to `arr[0]`, not `0` — initializing to `0` breaks for all-negative arrays #arrays #algorithm #gotcha
- Search: return `-1` as sentinel for "not found" #arrays #algorithm #pattern
- Swap pattern: always needs a `temp` variable — `temp = a; a = b; b = temp;` #arrays #pattern
- Shift left: loop forward, copy `arr[i+1]` into `arr[i]`, stop at `length - 1` to avoid out-of-bounds #arrays #algorithm #pattern
- Reverse in-place: swap from outside in, loop only to `arr.length / 2` #arrays #algorithm #pattern
