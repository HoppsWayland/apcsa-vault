## What's an Array?

An array is a fixed-size container that holds multiple values of the **same type**, stored in order. Instead of declaring 10 separate variables, you declare one array that holds 10 values.

```java
// Without an array — painful
int score0 = 85;
int score1 = 92;
int score2 = 78;
// ... and so on

// With an array — much better
int[] scores = {85, 92, 78, 90, 88};
```

---

## Declaring and Creating Arrays

**With initial values:**
```java
int[] scores = {85, 92, 78, 90, 88};
String[] names = {"Alice", "Bob", "Carol"};
double[] prices = {1.99, 2.50, 3.75};
```

**With a fixed size (values default to 0, false, or null):**
```java
int[] scores = new int[5];       // [0, 0, 0, 0, 0]
boolean[] flags = new boolean[3]; // [false, false, false]
String[] names = new String[4];  // [null, null, null, null]
```

The size is fixed at creation — you can't add or remove slots later. (That's what [[07 - ArrayLists/7.1 Intro to ArrayLists|ArrayLists]] are for.)

---

## Accessing Elements — Indexing

Each element has an **index** starting at **0**. Access elements using square brackets:

```java
int[] scores = {85, 92, 78, 90, 88};
//  index:        0   1   2   3   4

System.out.println(scores[0]);   // 85 — first element
System.out.println(scores[4]);   // 88 — last element
System.out.println(scores[2]);   // 78 — middle element
```

You can also assign to specific indices:
```java
scores[2] = 95;   // changes 78 to 95
```

---

## Array Length

`.length` (no parentheses — it's a field, not a method) gives the number of elements:

```java
int[] scores = {85, 92, 78, 90, 88};
System.out.println(scores.length);   // 5
```

The last valid index is always `scores.length - 1`. Accessing `scores[scores.length]` causes an **ArrayIndexOutOfBoundsException** — the most common array bug.

> [!WARNING] Off-By-One
> `scores[scores.length]` is out of bounds — indices go from `0` to `length - 1`. This is one of the most tested bugs on the AP exam.

## Try It — Array Basics

```run-java
public class Main {
    public static void main(String[] args) {
        int[] nums = {10, 20, 30, 40, 50};

        System.out.println("Length: " + nums.length);
        System.out.println("First: " + nums[0]);
        System.out.println("Last: " + nums[nums.length - 1]);

        // Modify an element
        nums[2] = 99;
        System.out.println("After change, index 2: " + nums[2]);

        // What happens with an out-of-bounds index?
        // Uncomment to see the error:
        // System.out.println(nums[5]);
    }
}
```

## Arrays are Objects

Arrays in Java are objects, which means the variable holds a **reference** to the array, not the array itself. This matters when you assign one array variable to another:

```run-java
public class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] b = a;      // b points to the SAME array

        b[0] = 99;
        System.out.println("a[0] = " + a[0]);   // 99 — a was changed too!
        System.out.println("b[0] = " + b[0]);   // 99
    }
}
```

`a` and `b` are both pointing at the same array in memory. Changing one changes both. If you want a true copy, you need to copy element by element (or use `Arrays.copyOf()`).

---

## 📌 Summary

- Arrays hold a fixed number of values of the **same type**; size cannot change after creation #arrays #concept
- Indices start at `0`; last valid index is `arr.length - 1` #arrays #syntax
- Accessing `arr[arr.length]` throws `ArrayIndexOutOfBoundsException` #arrays #gotcha
- Use `.length` (no parentheses) for arrays; use `.length()` (with parentheses) for Strings #arrays #strings #gotcha
- Array variables hold a reference — assigning `b = a` makes both point to the same array #arrays #concept #gotcha
- Default values when created with `new`: `0` for `int`, `0.0` for `double`, `false` for `boolean`, `null` for objects #arrays #syntax
