## Key Vocabulary

| Term | Meaning |
|------|---------|
| **Array** | A fixed-size sequence of values of the same type |
| **Index** | Position of an element, starting at 0 |
| **Length** | Number of elements; accessed via `.length` |
| **Traversal** | Visiting every element of an array |
| **for-each loop** | A loop that iterates over every element without an index |
| **Off-by-one error** | A bug caused by using the wrong index boundary |
