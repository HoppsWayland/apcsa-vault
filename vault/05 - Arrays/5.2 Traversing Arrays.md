## Traversal with a for Loop

The most common way to visit every element is a standard `for` loop using the index:

```java
int[] scores = {85, 92, 78, 90, 88};

for (int i = 0; i < scores.length; i++) {
    System.out.println(scores[i]);
}
```

Notice:
- Start at `i = 0` (first index)
- Condition is `i < scores.length` — not `<=` (that would go out of bounds)
- Access each element as `scores[i]`

---

## The for-each Loop

When you just need to visit every element and don't need the index, the **for-each loop** is cleaner:

```java
for (int score : scores) {
    System.out.println(score);
}
```

Read it as: *"for each int called `score` in `scores`"*

The for-each loop is simpler and less error-prone, but it has limitations — you can't:
- Access the index of the current element
- Modify the array (changes to the loop variable don't affect the original)
- Traverse backwards or skip elements

When you need any of those things, use a regular `for` loop.

---

## Try It — Both Loop Types

```run-java
public class Main {
    public static void main(String[] args) {
        String[] fruits = {"apple", "banana", "cherry", "date"};

        // for loop — with index
        System.out.println("With index:");
        for (int i = 0; i < fruits.length; i++) {
            System.out.println(i + ": " + fruits[i]);
        }

        // for-each — without index
        System.out.println("\nWith for-each:");
        for (String fruit : fruits) {
            System.out.println(fruit);
        }
    }
}
```

## Traversal Patterns

**Print all elements on one line:**
```java
for (int val : arr) {
    System.out.print(val + " ");
}
System.out.println();
```

**Modify every element (must use index-based loop):**
```java
for (int i = 0; i < arr.length; i++) {
    arr[i] = arr[i] * 2;   // double every element
}
```

**Traverse backwards:**
```java
for (int i = arr.length - 1; i >= 0; i--) {
    System.out.print(arr[i] + " ");
}
```

**Traverse all except first or last:**
```java
for (int i = 1; i < arr.length; i++) { ... }         // skip index 0
for (int i = 0; i < arr.length - 1; i++) { ... }    // skip last
```

## Try It — Modify and Traverse

```run-java
public class Main {
    public static void main(String[] args) {
        int[] nums = {3, 7, 2, 9, 4, 6, 1, 8};

        // Print original
        System.out.print("Original: ");
        for (int n : nums) System.out.print(n + " ");
        System.out.println();

        // Double every element
        for (int i = 0; i < nums.length; i++) {
            nums[i] *= 2;
        }

        // Print modified
        System.out.print("Doubled:  ");
        for (int n : nums) System.out.print(n + " ");
        System.out.println();

        // Print in reverse
        System.out.print("Reversed: ");
        for (int i = nums.length - 1; i >= 0; i--) {
            System.out.print(nums[i] + " ");
        }
    }
}
```

## 📌 Summary

- Standard traversal: `for (int i = 0; i < arr.length; i++)` — use `<`, not `<=` #arrays #loops #for #pattern
- For-each loop: `for (int val : arr)` — cleaner when index isn't needed #arrays #loops #for #pattern
- For-each cannot modify array elements or access the index — use index loop for those #arrays #loops #gotcha
- Traverse backwards: `for (int i = arr.length - 1; i >= 0; i--)` #arrays #loops #pattern
- Partial traversal: adjust start/end index (e.g. skip first with `i = 1`, skip last with `i < arr.length - 1`) #arrays #loops #pattern
