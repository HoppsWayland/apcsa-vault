## Arrays Aren't Just for Primitives

You've used arrays of `int` and `double`. But arrays can hold any type — including objects. An array of `Student` objects, an array of `BankAccount` objects, an array of `String` objects — all perfectly valid.

This is a very common FRQ pattern: you're given a class, and asked to write methods that work with an array of that class's objects.

---

## Declaring and Creating an Array of Objects

```java
// Declare an array that will hold 5 Student objects
Student[] roster = new Student[5];
```

At this point the array exists, but all 5 slots hold `null` — no actual Student objects yet. You have to create each one:

```java
roster[0] = new Student("Alice", 11, 3.8);
roster[1] = new Student("Bob",   10, 3.2);
roster[2] = new Student("Carol", 12, 3.9);
roster[3] = new Student("Dave",  11, 2.8);
roster[4] = new Student("Eve",   10, 3.5);
```

Or with an initializer list:
```java
Student[] roster = {
    new Student("Alice", 11, 3.8),
    new Student("Bob",   10, 3.2),
    new Student("Carol", 12, 3.9)
};
```

---

## Accessing Object Methods Through the Array

Use the index to get the object, then call methods on it:

```java
System.out.println(roster[0].getName());    // "Alice"
System.out.println(roster[2].getGpa());     // 3.9
roster[3].setGpa(3.1);                      // update Dave's GPA
```

The pattern is always: `array[index].method()`

## Try It — Array of Objects

```run-java
public class Main {

    static class Student {
        private String name;
        private int grade;
        private double gpa;

        public Student(String name, int grade, double gpa) {
            this.name  = name;
            this.grade = grade;
            this.gpa   = gpa;
        }

        public String getName()  { return name; }
        public int    getGrade() { return grade; }
        public double getGpa()   { return gpa; }

        public String toString() {
            return name + " (Gr." + grade + ", GPA:" + gpa + ")";
        }
    }

    public static void main(String[] args) {
        Student[] roster = {
            new Student("Alice", 11, 3.8),
            new Student("Bob",   10, 3.2),
            new Student("Carol", 12, 3.9),
            new Student("Dave",  11, 2.8),
            new Student("Eve",   10, 3.5)
        };

        // Print all students
        for (Student s : roster) {
            System.out.println(s);
        }

        // Find the student with the highest GPA
        Student topStudent = roster[0];
        for (int i = 1; i < roster.length; i++) {
            if (roster[i].getGpa() > topStudent.getGpa()) {
                topStudent = roster[i];
            }
        }
        System.out.println("Top student: " + topStudent.getName());
    }
}
```

## The Null Trap

When you create an array with `new Student[5]`, all slots are `null`. Calling a method on a null slot throws `NullPointerException`:

```java
Student[] roster = new Student[3];
System.out.println(roster[0].getName());   // NullPointerException! roster[0] is null
```

Always initialize each slot before using it, or check for null:

```java
for (Student s : roster) {
    if (s != null) {
        System.out.println(s.getName());
    }
}
```

## Common Algorithms on Object Arrays

**Find the element with the maximum field value:**
```java
Student topStudent = roster[0];
for (int i = 1; i < roster.length; i++) {
    if (roster[i].getGpa() > topStudent.getGpa()) {
        topStudent = roster[i];
    }
}
```

**Count elements matching a condition:**
```java
int seniorCount = 0;
for (Student s : roster) {
    if (s.getGrade() == 12) {
        seniorCount++;
    }
}
```

**Search for an element by a field value:**
```java
Student findByName(Student[] roster, String name) {
    for (Student s : roster) {
        if (s.getName().equals(name)) {
            return s;
        }
    }
    return null;   // not found
}
```

## Try It — Object Array Algorithms

```run-java
public class Main {

    static class Product {
        private String name;
        private double price;
        private int quantity;

        public Product(String name, double price, int quantity) {
            this.name     = name;
            this.price    = price;
            this.quantity = quantity;
        }

        public String getName()    { return name; }
        public double getPrice()   { return price; }
        public int    getQuantity(){ return quantity; }

        public double totalValue() { return price * quantity; }

        public String toString() {
            return name + " $" + price + " x" + quantity;
        }
    }

    public static void main(String[] args) {
        Product[] inventory = {
            new Product("Laptop",  999.99, 5),
            new Product("Mouse",    29.99, 50),
            new Product("Keyboard", 79.99, 20),
            new Product("Monitor", 399.99, 8),
            new Product("Headset",  59.99, 15)
        };

        // Total inventory value
        double total = 0;
        for (Product p : inventory) {
            total += p.totalValue();
        }
        System.out.printf("Total value: $%.2f%n", total);

        // Most expensive item
        Product priciest = inventory[0];
        for (int i = 1; i < inventory.length; i++) {
            if (inventory[i].getPrice() > priciest.getPrice()) {
                priciest = inventory[i];
            }
        }
        System.out.println("Most expensive: " + priciest.getName());

        // Count items under $100
        int affordable = 0;
        for (Product p : inventory) {
            if (p.getPrice() < 100) affordable++;
        }
        System.out.println("Items under $100: " + affordable);
    }
}
```

## 📌 Summary

- Arrays can hold objects of any class — declare with `ClassName[] arr = new ClassName[size]` #arrays #objects #syntax
- Newly created object arrays are filled with `null` — each slot must be initialized before use #arrays #objects #gotcha
- Access object methods through the array: `arr[i].method()` #arrays #objects #syntax
- Calling a method on a `null` array element throws `NullPointerException` #arrays #objects #gotcha
- Max/min by field: initialize to `arr[0]`, loop from index 1, compare using a getter #arrays #objects #algorithm
- Search by field value: loop and compare with `.equals()` for Strings, `==` for primitives #arrays #objects #algorithm #pattern
