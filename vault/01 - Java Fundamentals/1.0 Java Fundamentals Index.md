## Key Vocabulary

| Term | Meaning |
|------|---------|
| **Variable** | A named container for storing a value |
| **Data type** | Defines what kind of value a variable holds |
| **Primitive** | A basic data type: `int`, `double`, `boolean`, `char` |
| **Declaration** | Telling Java a variable exists and its type |
| **Initialization** | Giving a variable its first value |
| **Cast** | Temporarily converting a value to a different type |
| **Modulo** | The `%` operator — returns the remainder of division |
| **Concatenation** | Joining Strings together with `+` |
