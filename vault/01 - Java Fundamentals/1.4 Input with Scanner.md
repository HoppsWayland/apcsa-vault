## Getting Input from the User

So far all our programs have had data baked right in. Real programs need to *ask* the user for input. In Java, we use the `Scanner` class for this.

> [!NOTE] Scanner Shows Up Again
> You'll see Scanner in [[11 - File IO/11.1 Reading Files with Scanner|11.1 Reading Files with Scanner]] too — it's also used for reading from data files. Same class, different setup.

---

## Setting Up a Scanner

```java
import java.util.Scanner;   // goes at the very top of the file

Scanner scanner = new Scanner(System.in);
```

`System.in` tells the Scanner to read from the keyboard. Once you have a Scanner, call methods on it to read different types of input.

---

## Reading Different Types

| Method | What it reads | Returns |
|--------|--------------|---------|
| `nextInt()` | A whole number | `int` |
| `nextDouble()` | A decimal number | `double` |
| `next()` | One word (stops at whitespace) | `String` |
| `nextLine()` | A full line of text | `String` |

```java
import java.util.Scanner;

Scanner scanner = new Scanner(System.in);

System.out.print("Enter your name: ");
String name = scanner.nextLine();

System.out.print("Enter your age: ");
int age = scanner.nextInt();

System.out.println("Hi " + name + ", you are " + age + " years old.");
```

> [!TIP] `print` vs `println`
> `System.out.print()` does NOT add a newline — the cursor stays on the same line. Use it for prompts so the user types right after the question.

## Try It — Basic Input

```run-java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int num = scanner.nextInt();
        System.out.println(num + " squared is " + (num * num));
    }
}
```

## The `nextInt()` + `nextLine()` Trap ⚠️

This is one of the most common bugs beginners run into. When you call `nextInt()`, it reads the number but **leaves the newline character sitting in the buffer**. The very next `nextLine()` instantly "reads" that leftover newline and returns an empty string.

```java
Scanner scanner = new Scanner(System.in);

System.out.print("Enter your age: ");
int age = scanner.nextInt();

// BUG: This nextLine() grabs the leftover newline, not the user's input!
System.out.print("Enter your name: ");
String name = scanner.nextLine();   // gets "" immediately

System.out.println("Hi " + name);   // prints "Hi "  ← empty!
```

**The fix:** add an extra `scanner.nextLine()` right after `nextInt()` to flush the buffer:

```java
int age = scanner.nextInt();
scanner.nextLine();            // ← clears the leftover newline

String name = scanner.nextLine();   // now works correctly
```

> [!WARNING] This Is on the Exam
> The `nextInt()` + `nextLine()` interaction is explicitly part of the 2025-26 curriculum. Make sure you understand *why* it happens, not just how to fix it.

## 📌 Summary

- Import and create: `import java.util.Scanner;` then `Scanner sc = new Scanner(System.in);` #scanner #syntax
- `nextInt()`, `nextDouble()`, `next()`, `nextLine()` read different types #scanner #syntax
- `nextInt()` leaves a newline in the buffer — call `scanner.nextLine()` immediately after to clear it before reading a String #scanner #gotcha #pattern
- Use `System.out.print()` (not `println`) for prompts so the user types on the same line #scanner #syntax
