## What's a Variable?

Think of a variable as a labeled box. You give the box a name, declare what *type* of thing goes in it, and then you can store and retrieve values from it whenever you need them.

In Java, you always have to say what *type* of data the variable will hold — Java won't let you just toss anything in any box.

---

## Primitive Data Types

These are the basic building blocks. The AP exam focuses on four of them:

| Type | What it holds | Example |
|------|--------------|---------|
| `int` | Whole numbers | `42`, `-7`, `0` |
| `double` | Decimal numbers | `3.14`, `-0.5` |
| `boolean` | True or false only | `true`, `false` |
| `char` | A single character | `'A'`, `'z'`, `'!'` |

> [!NOTE] int vs double
> `int` can't hold a decimal — `int x = 3.14` will cause a compiler error. When in doubt about whether you'll need decimals, use `double`.

---

## Declaring and Initializing Variables

**Declaring** a variable means telling Java it exists and what type it is.
**Initializing** means giving it a value for the first time.

```java
// Declaration only
int score;

// Initialization (after declaring)
score = 95;

// Both at once — most common
int score = 95;
double gpa = 3.8;
boolean isPassing = true;
char grade = 'A';
```

> [!TIP] Naming Variables
> Use **camelCase** — start lowercase, capitalize each new word. `studentScore` is better than `s` or `student_score`. Names should be descriptive.

```run-java
public class Main {
```

## Integer Division — A Classic Trap

When you divide two `int` values in Java, the result is *always* an `int`. The decimal part is truncated (chopped off — not rounded).

```java
int a = 7;
int b = 2;
System.out.println(a / b);   // prints 3, not 3.5!
```

To get a decimal result, at least one value needs to be a `double`:

```java
double result  = 7.0 / 2;          // 3.5
double result2 = (double) 7 / 2;   // 3.5 — using a cast
```

That `(double)` is called a **cast** — it temporarily converts the value to a different type for that expression.

## The `final` Keyword — Constants

If a value should never change, declare it as `final`. By convention, constants are written in `ALL_CAPS`.

```java
final double PI = 3.14159;
final int MAX_SCORE = 100;
```

Trying to reassign a `final` variable causes a compiler error — Java enforces it.
