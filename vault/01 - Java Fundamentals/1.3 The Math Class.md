## What is the Math Class?

Java gives you a built-in `Math` class packed with useful mathematical methods. You don't need to create a Math object — you call the methods directly using `Math.methodName()`.

All the methods below are on the AP exam's Java Quick Reference sheet, so you'll always have them available on test day.

---

## `Math.abs(x)` — Absolute Value

Returns the positive version of any number.

```java
System.out.println(Math.abs(-5));    // 5
System.out.println(Math.abs(3.7));   // 3.7
System.out.println(Math.abs(0));     // 0
```

---

## `Math.pow(base, exponent)` — Exponentiation

Raises base to the power of exponent. **Always returns a `double`.**

```java
System.out.println(Math.pow(2, 10));    // 1024.0
System.out.println(Math.pow(3, 2));     // 9.0
System.out.println(Math.pow(16, 0.5));  // 4.0  ← square root!
```

> [!NOTE] Return Type
> `Math.pow()` always returns a `double`. If you need an `int`, cast it: `(int) Math.pow(2, 8)`

---

## `Math.sqrt(x)` — Square Root

Returns the square root as a `double`.

```java
System.out.println(Math.sqrt(25));   // 5.0
System.out.println(Math.sqrt(2));    // 1.4142135623730951
```

---

## `Math.random()` — Random Number

Returns a random `double` that is **≥ 0.0 and < 1.0**.

```java
System.out.println(Math.random());   // something like 0.7342...
```

By itself that's not super useful, but with a little math you can get random integers in any range.

---

## Generating Random Integers — The Formula

This pattern appears constantly on the AP exam:

```java
// Random int from 0 to n-1:
(int)(Math.random() * n)

// Random int from 1 to n:
(int)(Math.random() * n) + 1

// Random int from min to max (inclusive):
(int)(Math.random() * (max - min + 1)) + min
```

Examples:
```java
int die    = (int)(Math.random() * 6) + 1;    // 1–6
int rand   = (int)(Math.random() * 100);       // 0–99
int score  = (int)(Math.random() * 51) + 50;   // 50–100
```

> [!TIP] Why does the `(int)` cast work here?
> `Math.random()` returns something like `0.734`. Multiply by 6 → `4.404`. Cast to `int` → `4`. The decimal is chopped off, leaving a whole number in the right range.

## Try It — Math Methods

```run-java
public class Main {
    public static void main(String[] args) {
        System.out.println(Math.abs(-42));
        System.out.println(Math.pow(2, 8));
        System.out.println(Math.sqrt(144));

        // Run this a few times — output changes each time!

    }
```

## 📌 Summary

- `Math.abs(x)` — absolute value; works on `int` and `double` #math-class #syntax
- `Math.pow(base, exp)` — always returns `double`; cast to `int` if needed #math-class #syntax #gotcha
- `Math.sqrt(x)` — always returns `double` #math-class #syntax
- `Math.random()` — returns a `double` in range `[0.0, 1.0)` #math-class #syntax
