## Arithmetic Operators

Java supports the standard math operators you'd expect, plus one you might not:

| Operator | Meaning | Example | Result |
|----------|---------|---------|--------|
| `+` | Addition | `5 + 3` | `8` |
| `-` | Subtraction | `5 - 3` | `2` |
| `*` | Multiplication | `5 * 3` | `15` |
| `/` | Division | `5 / 2` | `2` (int!) |
| `%` | Modulo (remainder) | `5 % 2` | `1` |

The `%` operator is one of the most useful tools in AP CSA — it gives you the **remainder** after division.

---

## Modulo — More Useful Than It Looks

```java
System.out.println(10 % 3);   // 1  (10 = 3×3 + 1)
System.out.println(15 % 5);   // 0  (divides evenly)
System.out.println(7 % 10);   // 7  (7 is smaller than 10)
```

Common exam patterns:
- **Is a number even?** → `n % 2 == 0`
- **Is it divisible by x?** → `n % x == 0`
- **Get the last digit?** → `n % 10`
- **Wrap around a range?** → `n % size`

## Compound Assignment Operators

Shortcuts for updating a variable's own value:

| Shortcut | Equivalent to |
|----------|--------------|
| `x += 5` | `x = x + 5` |
| `x -= 3` | `x = x - 3` |
| `x *= 2` | `x = x * 2` |
| `x /= 4` | `x = x / 4` |
| `x %= 3` | `x = x % 3` |
| `x++` | `x = x + 1` |
| `x--` | `x = x - 1` |

`x++` and `x--` (increment and decrement) show up constantly in loops.

## Operator Precedence

Java follows the same order of operations as math — PEMDAS applies:
1. Parentheses `()`
2. Multiplication, Division, Modulo `* / %` — left to right
3. Addition, Subtraction `+ -` — left to right

```java
int result  = 2 + 3 * 4;      // 14, not 20
int result2 = (2 + 3) * 4;    // 20
```

When in doubt, use parentheses. Your code will be clearer and you won't get surprised.

## String Concatenation with `+`

When `+` is used with a `String`, it **concatenates** (joins) instead of adding.

```java
String name = "Alice";
int score = 95;
System.out.println("Score for " + name + ": " + score);
// Output: Score for Alice: 95
```

Watch out for this classic trap — once Java sees a `String` in a `+` chain, everything to the right also becomes concatenation:

```java
System.out.println("Result: " + 3 + 4);    // "Result: 34"  ← not what you wanted!
System.out.println("Result: " + (3 + 4));  // "Result: 7"   ← parentheses fix it
```

## 📌 Summary

- `%` returns the remainder after division: `10 % 3` → `1` #operators #syntax
- Even check: `n % 2 == 0`; odd check: `n % 2 != 0`; divisible by x: `n % x == 0` #operators #pattern #algorithm
- Get last digit of a number: `n % 10` #operators #pattern
- Compound assignment shortcuts: `x += 5`, `x *= 2`, `x++`, `x--` #operators #syntax
- Operator precedence: `* / %` before `+ -`; use parentheses when in doubt #operators #gotcha
- Once Java sees a `String` in a `+` chain, everything becomes concatenation: `"val: " + 3 + 4` → `"val: 34"` #strings #operators #gotcha
