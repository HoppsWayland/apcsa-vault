## Loops Inside Loops

A nested loop is simply a loop inside another loop. The **inner loop runs completely** for each single iteration of the outer loop.

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.print("(" + i + "," + j + ") ");
    }
    System.out.println();
}
```

Output:
```
(1,1) (1,2) (1,3)
(2,1) (2,2) (2,3)
(3,1) (3,2) (3,3)
```

Think of it like a clock: the inner loop (seconds) completes a full cycle every time the outer loop (minutes) ticks once.

---

## Counting Total Iterations

If the outer loop runs `m` times and the inner loop runs `n` times, the body of the inner loop runs `m × n` times total.

```java
for (int i = 0; i < 4; i++) {       // 4 times
    for (int j = 0; j < 5; j++) {   // 5 times each
        // runs 4 × 5 = 20 times total
    }
}
```

## Rectangular Patterns

To print a rectangle of characters, the outer loop controls rows and the inner loop controls columns:

```run-java
public class Main {
    public static void main(String[] args) {
        int rows = 4;
        int cols = 6;

        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                System.out.print("* ");
            }
            System.out.println();
        }
    }
}
```

Try changing `rows` and `cols` to different values.

## Triangular Patterns

Here's where nested loops get interesting. To print a triangle, the inner loop's range depends on the outer loop variable:

**Right triangle — growing:**
```run-java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int row = 1; row <= n; row++) {
            for (int col = 1; col <= row; col++) {   // inner goes up to row
                System.out.print("* ");
            }
            System.out.println();
        }
    }
}
```

**Right triangle — shrinking:**
```run-java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int row = n; row >= 1; row--) {
            for (int col = 1; col <= row; col++) {
                System.out.print("* ");
            }
            System.out.println();
        }
    }
}
```

**Number triangle:**
```run-java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int row = 1; row <= n; row++) {
            for (int col = 1; col <= row; col++) {
                System.out.print(col + " ");
            }
            System.out.println();
        }
    }
}
```

## Tracing Nested Loops

Tracing nested loops on the exam requires patience. Build a table tracking both loop variables:

```java
for (int i = 1; i <= 3; i++) {
    for (int j = i; j <= 3; j++) {
        System.out.print(i + "" + j + " ");
    }
    System.out.println();
}
```

| outer i | inner j | prints |
|---------|---------|--------|
| 1 | 1 | `11` |
| 1 | 2 | `12` |
| 1 | 3 | `13` |
| — | *newline* | |
| 2 | 2 | `22` |
| 2 | 3 | `23` |
| — | *newline* | |
| 3 | 3 | `33` |

Output:
```
11 12 13
22 23
33
```
