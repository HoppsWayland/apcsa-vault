## The if Statement

The most basic decision structure — run a block of code only if a condition is true:

```java
if (condition) {
    // runs only if condition is true
}
```

```java
int score = 85;
if (score >= 60) {
    System.out.println("Passing");
}
```

---

## if-else

Add an `else` to handle the case when the condition is false:

```java
if (score >= 60) {
    System.out.println("Passing");
} else {
    System.out.println("Failing");
}
```

Exactly one branch runs — either the `if` block or the `else` block, never both.

---

## if-else if-else

Chain multiple conditions with `else if`. Java checks them in order and runs the **first** one that's true:

```java
if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else if (score >= 70) {
    System.out.println("C");
} else if (score >= 60) {
    System.out.println("D");
} else {
    System.out.println("F");
}
```

> [!TIP] Order Matters
> Because Java stops at the first true condition, you can write `score >= 90` without also saying `score < 100`. If we reach `score >= 80`, we already know it's less than 90 (otherwise we'd have stopped at the first branch). This is a common source of bugs — make sure your conditions are in the right order.

## Nested Conditionals

You can put an `if` inside another `if`:

```java
if (age >= 18) {
    if (hasID) {
        System.out.println("Welcome!");
    } else {
        System.out.println("Need ID");
    }
} else {
    System.out.println("Too young");
}
```

This is equivalent to using `&&`:
```java
if (age >= 18 && hasID) {
    System.out.println("Welcome!");
} else if (age >= 18) {
    System.out.println("Need ID");
} else {
    System.out.println("Too young");
}
```

Nested conditionals are fine when the logic is genuinely nested, but they can get hard to read quickly. Use `&&` and `||` to simplify when you can.

---

## Common Mistake — The Dangling Else

When you omit braces `{}`, the `else` attaches to the nearest `if` — which may not be what you intended:

```java
// Looks like else belongs to outer if — but it doesn't!
if (x > 0)
    if (x > 10)
        System.out.println("Big");
else
    System.out.println("Not positive");   // actually pairs with inner if!
```

**Always use curly braces**, even for single-line bodies. It makes the structure unambiguous.

## 📌 Summary

- `if-else if-else` chains: Java stops at the **first** true condition — order matters #conditionals #gotcha
- Put more restrictive conditions first (e.g. `>= 90` before `>= 60`) #conditionals #gotcha #pattern
- Always use curly braces `{}` — the dangling else bug attaches `else` to the wrong `if` without them #conditionals #gotcha #syntax
- Nested `if` inside another `if` is fine, but `&&` is often cleaner #conditionals #pattern
- Using `=` (assignment) instead of `==` (comparison) in a condition is a compile error #conditionals #gotcha
