## The for Loop

A `for` loop packages the three loop components (initialize, condition, update) into one tidy line. It's the go-to loop when you know how many times you want to repeat.

```java
for (initialization; condition; update) {
    // body
}
```

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
// Prints: 0 1 2 3 4
```

The three parts run like this:
1. `int i = 0` — runs **once** at the start
2. `i < 5` — checked **before** each iteration
3. `i++` — runs **after** each iteration

---

## for vs while — Same Thing, Different Form

Any `for` loop can be rewritten as a `while` loop and vice versa:

```java
// for loop
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

// Equivalent while loop
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
```

Use a `for` when you know the count in advance. Use `while` when you don't (e.g. input validation, reading until a sentinel value).

## Common for Loop Patterns

**0-based (most common — matches array indices):**
```java
for (int i = 0; i < n; i++) { ... }
// i goes: 0, 1, 2, ..., n-1
```

**1-based:**
```java
for (int i = 1; i <= n; i++) { ... }
// i goes: 1, 2, 3, ..., n
```

**Counting down:**
```java
for (int i = 10; i >= 1; i--) { ... }
// i goes: 10, 9, 8, ..., 1
```

**Every other:**
```java
for (int i = 0; i < n; i += 2) { ... }
// i goes: 0, 2, 4, ...
```

**Traversing a String:**
```java
String word = "Hello";
for (int i = 0; i < word.length(); i++) {
    System.out.print(word.charAt(i) + " ");
}
// H e l l o
```

## Try It — for Loops

```run-java
public class Main {
    public static void main(String[] args) {
        // Sum of 1 to 10
        int sum = 0;
        for (int i = 1; i <= 10; i++) {
            sum += i;
        }
        System.out.println("Sum 1-10: " + sum);

        // Print even numbers 2-20
        for (int i = 2; i <= 20; i += 2) {
            System.out.print(i + " ");
        }
        System.out.println();

        // Traverse a String
        String word = "Computer";
        for (int i = 0; i < word.length(); i++) {
            System.out.print(word.charAt(i) + "-");
        }
    }
}
```

## Loop with Accumulator — Classic Patterns

These show up constantly on the AP exam:

```run-java
public class Main {
    public static void main(String[] args) {
        // Count how many even numbers are in range 1-20
        int evenCount = 0;
        for (int i = 1; i <= 20; i++) {
            if (i % 2 == 0) {
                evenCount++;
            }
        }
        System.out.println("Even numbers 1-20: " + evenCount);

        // Find the largest value
        int max = 1;
        for (int i = 1; i <= 10; i++) {
            int val = i * i;     // squares: 1, 4, 9, 16...
            if (val > max) {
                max = val;
            }
        }
        System.out.println("Largest square up to 10^2: " + max);
    }
}
```

## 📌 Summary

- `for (int i = 0; i < n; i++)` — 0-based, runs `n` times, indices `0` to `n-1` #loops #for #syntax
- Use `<` not `<=` in the condition when 0-based — `<= n` goes one too far #loops #for #gotcha
- Use `for` when the count is known; use `while` when it isn't #loops #concept
- Accumulator pattern: initialize before loop, update inside, use after #loops #pattern #algorithm
- `for-each` is cleaner for reading every element; regular `for` needed for index, modification, or reverse #loops #for #concept
