# 04 — Control Flow

[[Home|← Home]]

So far, every program we've written runs straight through from top to bottom. Control flow is how we make programs that make **decisions** and **repeat** actions. These are the building blocks of all algorithms.

## Key Vocabulary

| Term | Meaning |
|------|---------|
| **Boolean expression** | An expression that evaluates to `true` or `false` |
| **Condition** | The boolean expression tested by an `if` or loop |
| **Iteration** | One pass through a loop |
| **Infinite loop** | A loop whose condition never becomes false |
| **Nested loop** | A loop inside another loop |
| **Short-circuit evaluation** | `&&` and `\|\|` stop early when the result is certain |
