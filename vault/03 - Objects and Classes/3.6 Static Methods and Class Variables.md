## The Story So Far

Everything we've written in Unit 3 has been instance-based — each object has its own copy of data, and you call methods on a specific object. But Java has a second kind of member: **static** ones. Static members belong to the **class itself**, not to any individual object.

You've actually been using static things all along — `Math.random()`, `Math.sqrt()`, `Integer.MAX_VALUE`. Notice you never create a `Math` object. That's because those methods and fields are static.

---

## Static Methods

A static method belongs to the class, not to an instance. You call it using the class name, not an object reference.

```java
public class MathUtils {

    // Static method — no object needed to call it
    public static int square(int n) {
        return n * n;
    }

    public static boolean isEven(int n) {
        return n % 2 == 0;
    }
}
```

Calling it:
```java
int result = MathUtils.square(5);       // 25 — no object created
boolean even = MathUtils.isEven(10);    // true
```

> [!NOTE] When to Use Static Methods
> Static methods make sense for utility operations that don't depend on object state — pure computation like `Math.abs()` or `Math.random()`. If a method needs to read or change instance variables, it should be a regular (instance) method.

---

## Static Methods Can't Use Instance Variables

This is the key restriction. A static method has no `this` — it doesn't belong to any particular object, so it can't access instance data:

```java
public class Student {
    private String name;

    public static void greet() {
        System.out.println("Hello, " + name);   // COMPILE ERROR — name is an instance variable
    }
}
```

Static methods can only use:
- Their own parameters
- Local variables declared inside them
- Other static members of the class

## Try It — Static Utility Methods

```run-java
public class Main {

    static class Calculator {

        public static int add(int a, int b)      { return a + b; }
        public static int subtract(int a, int b) { return a - b; }
        public static int multiply(int a, int b) { return a * b; }

        public static double divide(int a, int b) {
            if (b == 0) return 0;
            return (double) a / b;
        }
    }

    public static void main(String[] args) {
        System.out.println(Calculator.add(10, 5));
        System.out.println(Calculator.multiply(6, 7));
        System.out.println(Calculator.divide(7, 2));
    }
}
```

## Static Fields — Class Variables

A static field is a variable that is **shared across all instances** of a class. There is exactly one copy, no matter how many objects exist.

```java
public class Student {
    private String name;
    private static int studentCount = 0;   // ONE copy, shared by all Students

    public Student(String name) {
        this.name = name;
        studentCount++;   // every new Student increments the shared counter
    }

    public static int getStudentCount() {
        return studentCount;
    }
}
```

```java
Student s1 = new Student("Alice");
Student s2 = new Student("Bob");
Student s3 = new Student("Carol");

System.out.println(Student.getStudentCount());   // 3
```

Each time a `Student` is created, the single shared `studentCount` goes up. It doesn't belong to Alice or Bob — it belongs to the `Student` class itself.

## Try It — Shared Counter

```run-java
public class Main {

    static class BankAccount {
        private String owner;
        private double balance;
        private static int totalAccounts = 0;   // shared across all accounts

        public BankAccount(String owner, double balance) {
            this.owner   = owner;
            this.balance = balance;
            totalAccounts++;
        }

        public static int getTotalAccounts() {
            return totalAccounts;
        }

        public String toString() {
            return owner + ": $" + balance;
        }
    }

    public static void main(String[] args) {
        System.out.println("Accounts: " + BankAccount.getTotalAccounts());  // 0

        BankAccount a1 = new BankAccount("Alice", 500);
        BankAccount a2 = new BankAccount("Bob", 300);

        System.out.println("Accounts: " + BankAccount.getTotalAccounts());  // 2
        System.out.println(a1);
        System.out.println(a2);

        BankAccount a3 = new BankAccount("Carol", 750);
        System.out.println("Accounts: " + BankAccount.getTotalAccounts());  // 3
    }
}
```

## Static vs Instance — Side by Side

```java
public class Counter {
    private int instanceCount = 0;         // each object has its own
    private static int classCount = 0;     // one shared copy

    public void increment() {
        instanceCount++;
        classCount++;
    }

    public int getInstanceCount()        { return instanceCount; }
    public static int getClassCount()    { return classCount; }
}
```

```run-java
public class Main {

    static class Counter {
        private int instanceCount = 0;
        private static int classCount = 0;

        public void increment() {
            instanceCount++;
            classCount++;
        }

        public int getInstanceCount()     { return instanceCount; }
        public static int getClassCount() { return classCount; }
    }

    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();

        c1.increment();
        c1.increment();
        c2.increment();

        System.out.println("c1 instance: " + c1.getInstanceCount());   // 2
        System.out.println("c2 instance: " + c2.getInstanceCount());   // 1
        System.out.println("class total: " + Counter.getClassCount());  // 3
    }
}
```

## 📌 Summary

- Static methods belong to the class, not an instance — call with `ClassName.method()` #methods #static #syntax
- Static methods cannot access instance variables — they have no `this` #methods #static #gotcha
- Use static methods for utility/computation that doesn't depend on object state #methods #static #concept
- Static fields are **class variables** — one shared copy regardless of how many objects exist #classes #static #concept
- Static fields are useful for counters, constants, or shared state across all instances #classes #static #pattern
- Access static members with the class name: `Student.getCount()`, not `s1.getCount()` #classes #static #syntax
