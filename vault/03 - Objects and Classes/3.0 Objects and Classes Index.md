## Key Vocabulary

| Term | Meaning |
|------|---------|
| **Object** | An instance of a class; bundles data and behavior |
| **Class** | The blueprint that defines what objects look like |
| **Instance variable** | A variable that belongs to each object |
| **Class variable** | A static variable shared by all instances of a class |
| **Constructor** | Special method that runs when an object is created |
| **Method** | A block of code that belongs to a class |
| **Static** | Belongs to the class itself, not any individual object |
| **Scope** | The region of code where a variable is accessible |
| **`this`** | Refers to the current object inside a class |
| **Encapsulation** | Hiding data inside a class; exposing it through methods |
