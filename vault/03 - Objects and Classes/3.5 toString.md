## The Problem With Printing Objects

Back in 3.3, you saw this:

```java
Student s = new Student("Alice", 11, 3.8);
System.out.println(s);   // prints something like: Student@4e50df2e
```

That weird output (`Student@4e50df2e`) is Java's default way of printing an object — the class name plus a memory address. Not exactly useful.

The fix is to override the `toString()` method.

---

## What is `toString()`?

Every class in Java automatically inherits a `toString()` method. By default it produces that ugly memory address output. But you can **override** it to return whatever String makes sense for your class.

Java automatically calls `toString()` whenever you:
- Pass an object to `System.out.println()`
- Concatenate an object with a String using `+`

```java
System.out.println(s);           // calls s.toString() automatically
System.out.println("Student: " + s);  // also calls s.toString()
```

---

## Writing toString()

The signature must match exactly:

```java
public String toString() {
    return /* some String describing this object */;
}
```

Here it is added to the `Student` class:

```java
public class Student {
    private String name;
    private int grade;
    private double gpa;

    public Student(String name, int grade, double gpa) {
        this.name  = name;
        this.grade = grade;
        this.gpa   = gpa;
    }

    @Override
    public String toString() {
        return name + " (Grade " + grade + ", GPA: " + gpa + ")";
    }
}
```

The `@Override` annotation is optional but good practice — it tells Java you intentionally mean to override the inherited method, and will give you a compile error if you accidentally misspell it.

## Try It — toString in Action

```run-java
public class Main {

    static class Student {
        private String name;
        private int grade;
        private double gpa;

        public Student(String name, int grade, double gpa) {
            this.name  = name;
            this.grade = grade;
            this.gpa   = gpa;
        }

        @Override
        public String toString() {
            return name + " (Grade " + grade + ", GPA: " + gpa + ")";
        }
    }

    public static void main(String[] args) {
        Student s1 = new Student("Alice", 11, 3.8);
        Student s2 = new Student("Bob",   10, 3.2);

        System.out.println(s1);
        System.out.println(s2);
        System.out.println("Top student: " + s1);
    }
}
```

## A Complete Class — Putting It All Together

Here's a full, well-designed class that brings together everything from this unit:

```run-java
public class Main {

    static class BankAccount {
        private String owner;
        private double balance;

        public BankAccount(String owner, double initialBalance) {
            this.owner   = owner;
            this.balance = initialBalance;
        }

        public String getOwner()   { return owner; }
        public double getBalance() { return balance; }

        public void deposit(double amount) {
            if (amount > 0) {
                balance += amount;
            }
        }

        public boolean withdraw(double amount) {
            if (amount > 0 && amount <= balance) {
                balance -= amount;
                return true;
            }
            return false;
        }

        @Override
        public String toString() {
            return owner + "'s account: $" + balance;
        }
    }

    public static void main(String[] args) {
        BankAccount acc = new BankAccount("Alice", 500.0);
        System.out.println(acc);

        acc.deposit(200.0);
        System.out.println("After deposit: " + acc);

        boolean success = acc.withdraw(100.0);
        System.out.println("Withdrawal successful: " + success);
        System.out.println(acc);

        boolean fail = acc.withdraw(1000.0);
        System.out.println("Big withdrawal successful: " + fail);
        System.out.println(acc);
    }
}
```

## 📌 Summary

- Without `toString()`, printing an object gives a useless memory address like `Student@4e50df2e` #methods #gotcha
- Override `toString()` with exact signature: `public String toString()` #methods #syntax
- Java calls `toString()` automatically when you pass an object to `println()` or use it in a `+` expression #methods #concept
- `@Override` annotation is optional but good practice — catches typos in the method signature #methods #syntax
- A well-designed class has: private fields, constructor(s), getters/setters, and `toString()` #classes #pattern
