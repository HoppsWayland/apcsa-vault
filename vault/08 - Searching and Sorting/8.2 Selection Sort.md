## The Idea

Selection sort works by repeatedly finding the minimum element and swapping it into its correct position at the front.

Pass 1: Find the minimum in the whole array → swap it to index 0
Pass 2: Find the minimum in indices 1 to end → swap it to index 1
Pass 3: Find the minimum in indices 2 to end → swap it to index 2
... and so on.

---

## Tracing Selection Sort

Array: `{64, 25, 12, 22, 11}`

| Pass | Array state | Action |
|------|-------------|--------|
| Start | `{64, 25, 12, 22, 11}` | |
| 1 | `{11, 25, 12, 22, 64}` | min=11 at index 4 → swap with index 0 |
| 2 | `{11, 12, 25, 22, 64}` | min=12 at index 2 → swap with index 1 |
| 3 | `{11, 12, 22, 25, 64}` | min=22 at index 3 → swap with index 2 |
| 4 | `{11, 12, 22, 25, 64}` | min=25 already at index 3 — no swap |
| Done | `{11, 12, 22, 25, 64}` | |

## Implementation

```run-java
public class Main {

    static void selectionSort(int[] arr) {
        for (int i = 0; i < arr.length - 1; i++) {
            // Find the index of the minimum in arr[i..end]
            int minIndex = i;
            for (int j = i + 1; j < arr.length; j++) {
                if (arr[j] < arr[minIndex]) {
                    minIndex = j;
                }
            }
            // Swap arr[i] and arr[minIndex]
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }

    public static void main(String[] args) {
        int[] arr = {64, 25, 12, 22, 11};

        System.out.print("Before: ");
        for (int n : arr) System.out.print(n + " ");
        System.out.println();

        selectionSort(arr);

        System.out.print("After:  ");
        for (int n : arr) System.out.print(n + " ");
    }
}
```

public class Main {

    static void selectionSortVerbose(int[] arr) {
        for (int i = 0; i < arr.length - 1; i++) {
            int minIndex = i;

        }

    public static void main(String[] args) {
        int[] arr = {64, 25, 12, 22, 11};
        selectionSortVerbose(arr);
    }
}

## Efficiency

Selection sort always does the same amount of work regardless of input order. For an array of `n` elements, the outer loop runs `n-1` times, and for each pass, the inner loop scans the remaining elements. Total comparisons ≈ n²/2.

For large arrays this is slow — but for the AP exam, you just need to understand and implement it correctly.

## 📌 Summary

- Selection sort: find the minimum in the unsorted portion, swap it to the front, repeat #sorting #algorithm
- After `k` passes, the first `k` elements are in their final sorted positions #sorting #concept #mc_only
- Always performs the same number of comparisons regardless of input order #sorting #concept #mc_only
- Swap requires a `temp` variable: `temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;` #sorting #pattern
- Outer loop runs `length - 1` times; inner loop scans from `i + 1` to end #sorting #syntax #pattern
