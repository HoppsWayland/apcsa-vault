## The Idea

Insertion sort builds a sorted portion from left to right. For each new element, it slides backward through the sorted portion until it finds its correct position — like sorting playing cards in your hand.

Pass 1: The first element is trivially sorted.
Pass 2: Take the second element, insert it into the correct position relative to the first.
Pass 3: Take the third element, slide it left until it's in the right spot.
... and so on.

---

## Tracing Insertion Sort

Array: `{5, 2, 4, 6, 1, 3}`

| Pass | Array state | Action |
|------|-------------|--------|
| Start | `{5, 2, 4, 6, 1, 3}` | |
| 1 | `{2, 5, 4, 6, 1, 3}` | 2 < 5 → slide left |
| 2 | `{2, 4, 5, 6, 1, 3}` | 4 slides past 5 |
| 3 | `{2, 4, 5, 6, 1, 3}` | 6 already in place |
| 4 | `{1, 2, 4, 5, 6, 3}` | 1 slides all the way left |
| 5 | `{1, 2, 3, 4, 5, 6}` | 3 slides to correct position |

## Implementation

```run-java
public class Main {

    static void insertionSort(int[] arr) {
        for (int i = 1; i < arr.length; i++) {
            int key = arr[i];   // the element we're inserting
            int j = i - 1;

            // Shift elements right until we find key's correct spot
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }
            arr[j + 1] = key;   // place key in its correct position
        }
    }

    public static void main(String[] args) {
        int[] arr = {5, 2, 4, 6, 1, 3};

        System.out.print("Before: ");
        for (int n : arr) System.out.print(n + " ");
        System.out.println();

        insertionSort(arr);

        System.out.print("After:  ");
        for (int n : arr) System.out.print(n + " ");
    }
}
```

        }
    }

        int[] arr = {5, 2, 4, 6, 1, 3};

## Selection Sort vs Insertion Sort

| | Selection Sort | Insertion Sort |
|---|---|---|
| **Strategy** | Find minimum, swap to front | Take next element, slide to correct spot |
| **Comparisons** | Always ~n²/2 | Fewer if data is nearly sorted |
| **Swaps/moves** | Exactly n-1 swaps | More moves, fewer swaps |
| **Best for** | When swaps are expensive | When data is nearly sorted |

Both are O(n²) in the worst case — neither is fast for large datasets. For the AP exam, focus on being able to implement and trace them correctly.

## 📌 Summary

- Insertion sort: take the next element, slide it left into its correct position in the sorted portion #sorting #algorithm
- Like sorting playing cards in your hand — build the sorted section one element at a time #sorting #concept #mc_only
- If input is already sorted, the inner `while` loop never executes — best case performance #sorting #concept #mc_only
- Insertion sort is faster than selection sort on nearly-sorted data #sorting #concept #mc_only
- The `key` variable holds the current element being inserted while others shift right to make room #sorting #pattern
