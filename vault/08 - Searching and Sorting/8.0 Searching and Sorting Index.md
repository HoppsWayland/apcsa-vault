## Key Vocabulary

| Term | Meaning |
|------|---------|
| **Linear search** | Check each element one at a time |
| **Binary search** | Repeatedly halve the search range (requires sorted data) |
| **Selection sort** | Find the minimum, swap it into place, repeat |
| **Insertion sort** | Build a sorted portion by inserting each element |
| **Efficiency** | How the number of operations grows with input size |
