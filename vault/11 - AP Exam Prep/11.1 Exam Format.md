## Overview

The AP Computer Science A exam is **3 hours** long and is taken digitally via the **College Board Bluebook** platform. It has two sections.

---

## Section I — Multiple Choice

- **42 questions**
- **90 minutes**
- Worth **55% of your score**
- Answer choices A through D (no E option)
- No penalty for wrong answers — always guess!

**What it tests:**
- Java syntax and semantics
- Tracing code by hand
- Understanding data structures (arrays, ArrayLists)
- OOP concepts (classes, methods, constructors)
- Recursion tracing
- Algorithm analysis

---

## Section II — Free Response

- **4 questions**
- **90 minutes** (~22 minutes each)
- Worth **45% of your score**
- Handwritten Java code in Bluebook
- The Java Quick Reference is available on screen the entire time

**The 4 FRQ types (each year):**

| Question | Type | Points |
|----------|------|--------|
| FRQ 1 | Methods and Control Structures | 9 pts |
| FRQ 2 | Class Writing | 9 pts |
| FRQ 3 | Array/ArrayList Manipulation | 5 pts |
| FRQ 4 | 2D Array | 6 pts |

---

## Bluebook Tips

- You can navigate between questions — don't get stuck on one
- Scratch paper is provided for tracing code
- The Java Quick Reference is always available (click to expand)
- Flag questions to review later

---

## Scoring

Raw scores are converted to a 1–5 scale:

| Score | Meaning |
|-------|---------|
| 5 | Extremely well qualified |
| 4 | Well qualified |
| 3 | Qualified |
| 2 | Possibly qualified |
| 1 | No recommendation |

Most colleges that award credit require a 3, 4, or 5. Check your target schools' policies.
