## The 4 FRQ Types

Every AP CSA exam has the same four types of FRQs. Knowing what to expect from each one is half the battle.

---

## FRQ 1 — Methods and Control Structures (9 pts)

**What it is:** A class is provided with some methods already written. You write 2–3 methods that use control structures (loops, conditionals) and may call the provided methods.

**Key skills:**
- Writing for/while loops correctly
- Using if/else logic
- Calling methods that are given to you
- Returning the right type

**Strategy:** Read all the provided methods first so you understand what tools you have. Often the hardest part is calling an existing method correctly — don't rewrite what's already there.

---

## FRQ 2 — Class Writing (9 pts)

**What it is:** Write a complete class from scratch — instance variables, constructor(s), and methods.

**Key skills:**
- Declaring private instance variables
- Writing a constructor using `this`
- Writing getters, setters, and computational methods
- Writing a `toString()` method

**Strategy:** Start with the instance variables and constructor — they give you points even if you don't finish the methods. Make sure your constructor initializes every instance variable.

---

## FRQ 3 — Array/ArrayList (5 pts)

**What it is:** Work with an ArrayList (arrays have been removed from this question for 2025-26). Write methods that traverse, filter, or modify the list.

**Key skills:**
- ArrayList traversal with index-based and for-each loops
- Removing elements while traversing (backwards loop!)
- Building a new ArrayList from conditions
- Calling ArrayList methods correctly (`get`, `set`, `add`, `remove`, `size`)

**Strategy:** Be especially careful with the remove-while-traversing bug. If you're removing elements, always loop backwards.

---

## FRQ 4 — 2D Array (6 pts)

**What it is:** Work with a 2D array. Usually involves traversal, searching, or computing something across rows/columns.

**Key skills:**
- Accessing elements with `arr[r][c]`
- Nested loops for full traversal
- Row-sum, column-sum, diagonal patterns
- Finding max/min across the grid

**Strategy:** Draw the grid on your scratch paper. Label the row and column indices. Trace your loops manually before writing.

---

## General FRQ Strategies

**Write something for every part.** Partial credit is awarded. A blank answer gets 0. Even a loop with the wrong body might get 1 point.

**Use the Java Quick Reference.** It's on screen the whole time. Don't waste time trying to remember exact method signatures — look them up.

**Don't rewrite provided code.** If a method is given to you, call it. Rewriting it wastes time and can lose you points if you get it slightly wrong.

**Show your logic even if you're unsure.** Comments won't get you points, but they won't hurt either. Clear code structure helps graders give partial credit.

**Watch your syntax.** Semicolons, curly braces, and correct method call syntax matter. Common losses:
- Missing semicolons
- Using `=` instead of `==`
- Using `==` instead of `.equals()` for Strings
- Off-by-one errors in loop bounds
