# 11.4 Common Mistakes

These are the mistakes that cost AP CSA students the most points. Go through this list before every practice FRQ.

---

## Strings

**Using `==` instead of `.equals()`**
```java
// WRONG
if (word == "hello") { ... }

// RIGHT
if (word.equals("hello")) { ... }
```
→ [[02 - Strings/2.3 String Comparisons|2.3 String Comparisons]]

---

**Off-by-one in `substring`**
```java
String s = "hello";
s.substring(1, 4)   // "ell" — end index is EXCLUSIVE
s.substring(1, 5)   // "ello" — to get the last character, use length()
```
→ [[02 - Strings/2.2 String Methods|2.2 String Methods]]

---

**Not saving the result of String methods (immutability)**
```java
// WRONG — does nothing
s.toUpperCase();

// RIGHT
s = s.toUpperCase();
```

## Arrays

**Off-by-one: going out of bounds**
```java
// WRONG — arr[arr.length] doesn't exist
for (int i = 0; i <= arr.length; i++) { ... }

// RIGHT
for (int i = 0; i < arr.length; i++) { ... }
```
→ [[05 - Arrays/5.1 Intro to Arrays|5.1 Intro to Arrays]]

---

**Initializing max/min to 0 instead of first element**
```java
// WRONG — breaks for all-negative arrays
int max = 0;

// RIGHT
int max = arr[0];
```
→ [[05 - Arrays/5.3 Array Algorithms|5.3 Array Algorithms]]

---

**Trying to modify array with for-each**
```java
// WRONG — doesn't change the array
for (int n : arr) { n = n * 2; }

// RIGHT
for (int i = 0; i < arr.length; i++) { arr[i] *= 2; }
```

---

## ArrayLists

**Using `.length` instead of `.size()`**
```java
// WRONG
list.length

// RIGHT
list.size()
```

---

**Removing forward while traversing — skips elements**
```java
// WRONG — skips elements after each removal
for (int i = 0; i < list.size(); i++) {
    if (shouldRemove(list.get(i))) list.remove(i);
}

// RIGHT — traverse backward
for (int i = list.size() - 1; i >= 0; i--) {
    if (shouldRemove(list.get(i))) list.remove(i);
}
```
→ [[07 - ArrayLists/7.4 Traversing ArrayLists|7.4 Traversing ArrayLists]]

---

**`remove(int)` vs `remove(Object)` confusion**
```java
ArrayList<Integer> nums = ...;
nums.remove(2);                    // removes INDEX 2
nums.remove(Integer.valueOf(2));   // removes VALUE 2
```

---

## Classes and Objects

**Forgetting `this` when parameter names shadow instance variables**
```java
// WRONG — sets parameter to itself, instance variable unchanged
public Student(String name) {
    name = name;
}

// RIGHT
public Student(String name) {
    this.name = name;
}
```
→ [[03 - Objects and Classes/3.3 Constructors|3.3 Constructors]]

---

**Not returning from a non-void method**
```java
// WRONG — compile error
public double getArea() {
    double area = width * height;
    // forgot return!
}

// RIGHT
public double getArea() {
    return width * height;
}
```

---

## Control Flow

**Using `=` (assignment) instead of `==` (comparison)**
```java
// WRONG — always true, assigns 5 to x
if (x = 5) { ... }

// RIGHT
if (x == 5) { ... }
```

---

**Incorrect order in if-else if chains**
```java
// WRONG — everything ≥ 60 gets "D", never reaches "A" or "B"
if (score >= 60) System.out.println("D");
else if (score >= 90) System.out.println("A");

// RIGHT — most restrictive first
if (score >= 90) System.out.println("A");
else if (score >= 60) System.out.println("D");
```

---

## Recursion

**No base case — causes StackOverflowError**
```java
// WRONG
static int sum(int n) {
    return n + sum(n - 1);   // never stops!
}

// RIGHT
static int sum(int n) {
    if (n == 0) return 0;    // base case
    return n + sum(n - 1);
}
```
→ [[09 - Recursion/9.1 Intro to Recursion|9.1 Intro to Recursion]]

## File I/O

**Missing `throws FileNotFoundException`**
```java
// WRONG — won't compile
public static void main(String[] args) {
    Scanner sc = new Scanner(new File("data.txt"));
}

// RIGHT
public static void main(String[] args) throws FileNotFoundException {
    Scanner sc = new Scanner(new File("data.txt"));
}
```
→ [[10 - File IO/10.1 Reading Files with Scanner|10.1 Reading Files with Scanner]]
