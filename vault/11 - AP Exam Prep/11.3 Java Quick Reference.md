## String Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `s.length()` | `int` | Number of characters |
| `s.substring(from, to)` | `String` | Characters from index `from` up to (not including) `to` |
| `s.substring(from)` | `String` | Characters from index `from` to end |
| `s.indexOf(str)` | `int` | Index of first occurrence of `str`, or `-1` |
| `s.equals(other)` | `boolean` | True if same content |
| `s.compareTo(other)` | `int` | Negative/0/positive for before/equal/after |

> [!WARNING] charAt() Not on Reference
> `charAt()` is valid Java but not on the 2025-26 Quick Reference. Use `substring(i, i+1)` in exam answers.

→ See [[02 - Strings/2.2 String Methods|2.2 String Methods]] and [[02 - Strings/2.3 String Comparisons|2.3 String Comparisons]]

## ArrayList Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `list.add(obj)` | `void` | Appends obj to end |
| `list.add(index, obj)` | `void` | Inserts obj at index |
| `list.get(index)` | element type | Returns element at index |
| `list.set(index, obj)` | element type | Replaces element; returns old value |
| `list.remove(index)` | element type | Removes and returns element at index |
| `list.size()` | `int` | Number of elements |
| `list.indexOf(obj)` | `int` | Index of first occurrence, or `-1` |
| `list.contains(obj)` | `boolean` | True if obj is in the list |

→ See [[07 - ArrayLists/7.3 ArrayList Methods|7.3 ArrayList Methods]]

## Scanner Methods (for File I/O)

| Method | Returns | Description |
|--------|---------|-------------|
| `sc.hasNext()` | `boolean` | True if more tokens exist |
| `sc.hasNextInt()` | `boolean` | True if next token is an int |
| `sc.hasNextDouble()` | `boolean` | True if next token is a double |
| `sc.hasNextLine()` | `boolean` | True if another line exists |
| `sc.next()` | `String` | Returns next token |
| `sc.nextInt()` | `int` | Returns next int token |
| `sc.nextDouble()` | `double` | Returns next double token |
| `sc.nextLine()` | `String` | Returns rest of current line |

→ See [[10 - File IO/10.1 Reading Files with Scanner|10.1 Reading Files with Scanner]]
