## The Methods You Need to Know

All of these are on the AP Java Quick Reference sheet.

| Method | What it does |
|--------|-------------|
| `add(obj)` | Appends obj to the end |
| `add(index, obj)` | Inserts obj at index, shifts right |
| `get(index)` | Returns element at index |
| `set(index, obj)` | Replaces element at index, returns old value |
| `remove(index)` | Removes element at index, shifts left, returns removed value |
| `size()` | Returns number of elements |
| `indexOf(obj)` | Returns index of first occurrence, or -1 |
| `contains(obj)` | Returns true if obj is in the list |

## add, get, set, remove

```run-java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        // add to end
        list.add("Alice");
        list.add("Bob");
        list.add("Carol");
        System.out.println(list);   // [Alice, Bob, Carol]

        // add at index
        list.add(1, "Beth");
        System.out.println(list);   // [Alice, Beth, Bob, Carol]

        // get
        System.out.println(list.get(2));   // Bob

        // set — returns old value
        String old = list.set(0, "Anna");
        System.out.println("Replaced: " + old);
        System.out.println(list);   // [Anna, Beth, Bob, Carol]

        // remove by index — returns removed value
        String removed = list.remove(1);
        System.out.println("Removed: " + removed);
        System.out.println(list);   // [Anna, Bob, Carol]
    }
}
```

## The `remove` Ambiguity With Integers

For `ArrayList<Integer>`, `remove(int)` is ambiguous — does it remove by index or by value?

```java
ArrayList<Integer> nums = new ArrayList<>();
nums.add(10);
nums.add(20);
nums.add(30);

nums.remove(1);            // removes INDEX 1 (value 20) — int is treated as index!
nums.remove(Integer.valueOf(10));   // removes VALUE 10 — must wrap to force value removal
```

To remove by **value** from an Integer list, wrap the value: `remove(Integer.valueOf(x))`.

## contains and indexOf

```run-java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();
        list.add("apple");
        list.add("banana");
        list.add("cherry");
        list.add("banana");

        System.out.println(list.contains("banana"));    // true
        System.out.println(list.contains("grape"));     // false
        System.out.println(list.indexOf("banana"));     // 1 (first occurrence)
        System.out.println(list.indexOf("grape"));      // -1 (not found)
    }
}
```

## Passing ArrayLists to Methods

ArrayLists are objects, so they're passed by reference. A method that receives an ArrayList can modify the original:

```run-java
import java.util.ArrayList;

public class Main {

    static void addDouble(ArrayList<Integer> list) {
        for (int i = 0; i < list.size(); i++) {
            list.set(i, list.get(i) * 2);
        }
    }

    public static void main(String[] args) {
        ArrayList<Integer> nums = new ArrayList<>();
        nums.add(1);
        nums.add(2);
        nums.add(3);

        System.out.println("Before: " + nums);
        addDouble(nums);
        System.out.println("After:  " + nums);   // modified!
    }
}
```

## 📌 Summary

- `add(obj)` appends to end; `add(index, obj)` inserts and shifts right #arraylists #syntax
- `set(index, obj)` replaces and returns the old value; `remove(index)` removes and returns the removed value #arraylists #syntax
- For `ArrayList<Integer>`, `remove(2)` removes by **index** — use `remove(Integer.valueOf(2))` to remove by **value** #arraylists #gotcha
- `contains(obj)` and `indexOf(obj)` use `.equals()` internally — works correctly for Strings and wrapper types #arraylists #syntax #concept
- Methods that receive an ArrayList can modify the original — ArrayLists are passed by reference #arraylists #concept #gotcha
