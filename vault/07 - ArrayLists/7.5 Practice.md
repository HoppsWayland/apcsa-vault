## Exercise 3 — Interleave

Given two ArrayLists of the same size, create a third list that interleaves them: element 0 from list A, element 0 from list B, element 1 from A, element 1 from B, etc.

```run-java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> a = new ArrayList<>();
        ArrayList<String> b = new ArrayList<>();

        for (String s : new String[]{"A1","A2","A3","A4"}) a.add(s);
        for (String s : new String[]{"B1","B2","B3","B4"}) b.add(s);

        // Your code — create and print interleaved list
        // Expected: [A1, B1, A2, B2, A3, B3, A4, B4]

    }
}
```
