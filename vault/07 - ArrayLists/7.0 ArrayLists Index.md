# 07 — ArrayLists

[[Home|← Home]]

Arrays are great, but their fixed size is a real limitation. ArrayLists give you a resizable list that can grow and shrink dynamically. They're the workhorses of Java data storage, and they have their own FRQ question on the AP exam.

## Key Vocabulary

| Term | Meaning |
|------|---------|
| **ArrayList** | A resizable list of objects |
| **Wrapper class** | An object version of a primitive (`Integer`, `Double`, `Boolean`) |
| **Autoboxing** | Automatic conversion from primitive to wrapper |
| **Unboxing** | Automatic conversion from wrapper to primitive |
| **Generic type** | The type in `<>` that specifies what an ArrayList holds |
