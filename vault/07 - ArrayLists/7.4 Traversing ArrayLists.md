## for-each Traversal

The cleanest way when you just need to read every element:

```java
ArrayList<String> names = new ArrayList<>();
// ... add elements ...

for (String name : names) {
    System.out.println(name);
}
```

---

## Index-Based Traversal

Use this when you need the index, need to modify elements, or need to remove items:

```java
for (int i = 0; i < names.size(); i++) {
    System.out.println(i + ": " + names.get(i));
}
```

Note: it's `names.size()`, not `names.length`.

---

## Removing While Traversing — The Classic Bug

This is one of the most tested ArrayList topics on the AP exam. If you use a for-each loop and try to remove elements, you'll get a `ConcurrentModificationException`. And if you use an index loop carelessly, you'll skip elements.

**The problem:**
```java
// BUGGY — skips elements!
for (int i = 0; i < list.size(); i++) {
    if (list.get(i) < 0) {
        list.remove(i);   // after removal, indices shift — next element gets skipped!
    }
}
```

**The fix — iterate backwards:**
```java
for (int i = list.size() - 1; i >= 0; i--) {
    if (list.get(i) < 0) {
        list.remove(i);   // removing from the end doesn't affect earlier indices
    }
}
```

When you traverse backwards and remove elements, the removal only affects indices *after* the current position (which you've already visited), so nothing gets skipped.

## Try It — The Skip Bug

Run the buggy version first to see what happens, then try the fix:

```run-java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> nums = new ArrayList<>();
        for (int n : new int[]{3, -1, -2, 5, -4, 6, -7, 8}) {
            nums.add(n);
        }

        System.out.println("Before: " + nums);

        // BUGGY forward loop
        for (int i = 0; i < nums.size(); i++) {
            if (nums.get(i) < 0) {
                nums.remove(i);
            }
        }

        System.out.println("After (buggy): " + nums);
        // Some negatives survived!
    }
}
```

```run-java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
```

## Building an ArrayList From Conditions

A common pattern — filter or transform one list into another:

```run-java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> original = new ArrayList<>();
        for (int i = 1; i <= 20; i++) original.add(i);

        // Build a new list of only even numbers
        ArrayList<Integer> evens = new ArrayList<>();
        for (int n : original) {
            if (n % 2 == 0) {
                evens.add(n);
            }
        }

        System.out.println("Evens: " + evens);
    }
}
```

## 📌 Summary

- For-each is cleanest for read-only traversal; index loop needed for modification or removal #arraylists #loops #pattern
- **Never remove while traversing forward** — removing shifts indices and causes elements to be skipped #arraylists #gotcha
- Safe removal pattern: traverse **backwards** with `for (int i = list.size() - 1; i >= 0; i--)` #arraylists #loops #pattern #algorithm
- Build a filtered list: loop the original, conditionally `add()` to a new ArrayList #arraylists #algorithm #pattern
