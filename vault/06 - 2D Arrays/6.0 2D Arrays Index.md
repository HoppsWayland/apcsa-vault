# 06 — 2D Arrays

[[Home|← Home]]

A 2D array is an array of arrays — think of it like a grid or table. They're used to represent things like game boards, spreadsheets, images, and matrices. On the AP exam, 2D arrays appear in their own dedicated FRQ question.

## Key Vocabulary

| Term | Meaning |
|------|---------|
| **2D array** | An array whose elements are themselves arrays |
| **Row** | A horizontal slice; first index |
| **Column** | A vertical slice; second index |
| **Row-major order** | Traversing row by row (outer loop = rows) |
| **`arr[r][c]`** | Element at row `r`, column `c` |
