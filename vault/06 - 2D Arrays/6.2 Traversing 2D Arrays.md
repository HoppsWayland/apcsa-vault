## Row-Major Traversal

The standard way to visit every element — outer loop over rows, inner loop over columns:

```java
for (int r = 0; r < grid.length; r++) {
    for (int c = 0; c < grid[0].length; c++) {
        System.out.print(grid[r][c] + " ");
    }
    System.out.println();   // newline after each row
}
```

This visits elements left-to-right, top-to-bottom — row 0 completely, then row 1, then row 2.

---

## Column-Major Traversal

Swap the loops to go column by column instead:

```java
for (int c = 0; c < grid[0].length; c++) {
    for (int r = 0; r < grid.length; r++) {
        System.out.print(grid[r][c] + " ");
    }
    System.out.println();
}
```

This visits every element in column 0 top-to-bottom, then column 1, etc.

---

## Try It — Row vs Column Traversal

```run-java
public class Main {
    public static void main(String[] args) {
        int[][] grid = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };

        System.out.println("Row-major:");
        for (int r = 0; r < grid.length; r++) {
            for (int c = 0; c < grid[0].length; c++) {
                System.out.printf("%3d", grid[r][c]);
            }
            System.out.println();
        }

        System.out.println("\nColumn-major:");
        for (int c = 0; c < grid[0].length; c++) {
            for (int r = 0; r < grid.length; r++) {
                System.out.printf("%3d", grid[r][c]);
            }
            System.out.println();
        }
    }
}
```

## Algorithms on 2D Arrays

The same patterns from 1D arrays apply here — just with two indices.

**Sum of all elements:**
```run-java
public class Main {
    public static void main(String[] args) {
        int[][] grid = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };

        int sum = 0;
        for (int[] row : grid) {
            for (int val : row) {
                sum += val;
            }
        }
        System.out.println("Sum: " + sum);
    }
}
```

Notice the for-each trick: `for (int[] row : grid)` gives you each row as a 1D array, then `for (int val : row)` iterates over that row's elements.

**Find max in entire grid:**
```java
int max = grid[0][0];
for (int[] row : grid) {
    for (int val : row) {
        if (val > max) max = val;
    }
}
```

**Sum of a single row:**
```java
int rowSum = 0;
for (int c = 0; c < grid[0].length; c++) {
    rowSum += grid[targetRow][c];
}
```

**Sum of a single column:**
```java
int colSum = 0;
for (int r = 0; r < grid.length; r++) {
    colSum += grid[r][targetCol];
}
```

## Diagonal Traversal

The main diagonal (top-left to bottom-right) has indices where `r == c`:

```run-java
public class Main {
    public static void main(String[] args) {
        int[][] grid = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };

        System.out.print("Main diagonal: ");
        for (int i = 0; i < grid.length; i++) {
            System.out.print(grid[i][i] + " ");   // r == c
        }
    }
}
```

## 📌 Summary

- Row-major traversal: outer loop over rows (`arr.length`), inner loop over columns (`arr[0].length`) #2d-arrays #loops #nested #pattern
- Column-major traversal: swap the loops — outer over columns, inner over rows #2d-arrays #loops #pattern
- For-each trick: `for (int[] row : grid)` gives each row as a 1D array #2d-arrays #loops #pattern
- Main diagonal elements: where `row == col` #2d-arrays #algorithm #pattern
- Row sum: fix the row index, loop over columns; column sum: fix the column index, loop over rows #2d-arrays #algorithm #pattern
