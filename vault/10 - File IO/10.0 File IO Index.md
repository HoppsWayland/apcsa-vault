# 10 — File I/O

[[Home|← Home]]

Reading data from files is new to the 2025-26 AP CSA curriculum. It's a practical skill — real programs rarely have their data hardcoded. The Scanner class you used for keyboard input works for files too, with a slightly different setup.

## Key Vocabulary

| Term | Meaning |
|------|---------|
| **File** | A named collection of data stored on disk |
| **Scanner** | The class used to read from files or keyboard |
| **`hasNext()`** | Returns true if there's more data to read |
| **`hasNextLine()`** | Returns true if there's another line |
| **`FileNotFoundException`** | Exception thrown when the file doesn't exist |
| **`throws`** | Declares that a method may throw a checked exception |
