## Reading Mixed Data

Files often contain a mix of strings and numbers. You can read tokens of different types in sequence:

```run-java
import java.util.Scanner;
import java.io.File;
import java.io.FileWriter;

public class Main {
    public static void main(String[] args) throws Exception {
        // Create data file: name score
        FileWriter fw = new FileWriter("grades.txt");
        fw.write("Alice 95\nBob 82\nCarol 91\nDave 78\nEve 88\n");
        fw.close();

        Scanner sc = new Scanner(new File("grades.txt"));
        int total = 0;
        int count = 0;

        while (sc.hasNext()) {
            String name  = sc.next();       // read name (String token)
            int    score = sc.nextInt();    // read score (int token)
            System.out.println(name + ": " + score);
            total += score;
            count++;
        }

        sc.close();
        System.out.printf("Average: %.1f%n", (double) total / count);
    }
}
```

## Reading Line by Line and Parsing

Sometimes it's cleaner to read a full line and then split or parse it:

```run-java
import java.util.Scanner;
import java.io.File;
import java.io.FileWriter;

public class Main {
    public static void main(String[] args) throws Exception {
        // CSV-style data: name,score,grade
        FileWriter fw = new FileWriter("students.txt");
        fw.write("Alice,95,A\nBob,82,B\nCarol,91,A\nDave,78,C\n");
        fw.close();

        Scanner sc = new Scanner(new File("students.txt"));

        while (sc.hasNextLine()) {
            String line = sc.nextLine();
            Scanner lineScanner = new Scanner(line);
            lineScanner.useDelimiter(",");   // split on commas

            String name  = lineScanner.next();
            int    score = lineScanner.nextInt();
            String grade = lineScanner.next();

            System.out.println(name + " got a " + grade + " (" + score + ")");
            lineScanner.close();
        }

        sc.close();
    }
}
```

## Computing Statistics From a File

A classic AP pattern — read a file of numbers and compute summary statistics:

```run-java
import java.util.Scanner;
import java.io.File;
import java.io.FileWriter;

public class Main {
    public static void main(String[] args) throws Exception {
        // Write a file of numbers
        FileWriter fw = new FileWriter("numbers.txt");
        fw.write("34 12 67 8 45 23 91 5 78 56\n");
        fw.close();

        Scanner sc = new Scanner(new File("numbers.txt"));

        int count = 0;
        int sum   = 0;
        int max   = Integer.MIN_VALUE;
        int min   = Integer.MAX_VALUE;

        while (sc.hasNextInt()) {
            int n = sc.nextInt();
            count++;
            sum += n;
            if (n > max) max = n;
            if (n < min) min = n;
        }

        sc.close();

        System.out.println("Count: " + count);
        System.out.println("Sum:   " + sum);
        System.out.printf("Avg:   %.2f%n", (double) sum / count);
        System.out.println("Max:   " + max);
        System.out.println("Min:   " + min);
    }
}
```

> [!TIP] Integer.MIN_VALUE and Integer.MAX_VALUE
> Using these as starting values for min/max is cleaner than using the first element — especially when reading a file where you might not know how many values there are before the loop starts.

## Loading File Data Into an ArrayList

```run-java
import java.util.Scanner;
import java.util.ArrayList;
import java.io.File;
import java.io.FileWriter;

public class Main {
    public static void main(String[] args) throws Exception {
        FileWriter fw = new FileWriter("words.txt");
        fw.write("apple\nbanana\ncherry\ndate\nelderberry\n");
        fw.close();

        ArrayList<String> words = new ArrayList<>();
        Scanner sc = new Scanner(new File("words.txt"));

        while (sc.hasNextLine()) {
            words.add(sc.nextLine().trim());   // trim removes stray whitespace
        }

        sc.close();
        System.out.println("Loaded " + words.size() + " words: " + words);
    }
}
```

## 📌 Summary

- Read mixed data (name + number on same line): call `sc.next()` then `sc.nextInt()` in sequence #file-io #scanner #pattern
- Parse CSV: read each line with `nextLine()`, create a second `Scanner` on the line with `useDelimiter(",")` #file-io #scanner #pattern
- Use `Integer.MIN_VALUE` / `Integer.MAX_VALUE` as starting values for min/max when reading unknown data #file-io #algorithm #pattern
- Load file data into an ArrayList for flexible downstream processing #file-io #arraylists #pattern
- `trim()` on each line removes stray whitespace that can cause unexpected comparison failures #file-io #strings #gotcha
